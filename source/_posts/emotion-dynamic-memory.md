## 一句话概括

把“情绪”从一个静态标签，升级为**可量化、可长期演化、可解释**的智能体内在状态：三层架构（感知 → 处理 → 决策）先把语音与文本编码成七维情绪向量，再经长期记忆、情感态度、情感传染、性格修正等模块耦合修正，最后驱动一套“以情绪为奖励”的策略，在长期交互中逐步收敛并沉淀出稳定人格。

## 1. 要解决的问题

现有 AI 情绪方案基本是三代，都有明显短板：

| 方案 | 做法 | 短板 |
| --- | --- | --- |
| 情感分类 + 策略回复 | 用 CNN/RNN/Transformer 分类用户情绪，再按标签匹配模板 | 单点识别、无上下文、无情绪演化，模板痕迹重 |
| 情绪强化的大语言模型 | 用情绪控制 token / 参数注入“用户=悲伤，AI=温柔” | 情绪是静态特征，不随上下文演化，无长期记忆、易突兀 |
| 情绪状态机 | 给 AI 若干情绪状态，按关键词得分切换 | 状态有限，无法跨场景转换 |

核心痛点是：**标签数量有限，难以处理未定义的交互模式，导致机器人性格受限**（对比 CN120921385A 通过离散标签累加获得性格的方案）。

## 2. 总体架构

系统以 LLM 二次开发为底座，提出**感知层 / 处理层 / 决策层**三层架构，让智能体分别承担“数据分析 / 数据处理 / 状态决策”三类工作，形成“情绪—态度—记忆—策略”闭环。

![系统总体流程概览](/images/emotion-agent/overview.png)

*系统总体流程概览（专利摘要附图）：输入经感知得到 1×7 机器人情绪与 1×7 用户情绪；机器人情绪进入“情绪修正模块”（长期记忆 / 情感态度 / 情感传染 / 性格模块循环修正），用户情绪则通过情感态度累加与情感传染修正；修正完成后进入决策，结果经判断回到性格模块累加。*

## 3. 感知层：把语音与文本编码成情绪向量

感知层是智能体的输入入口，包含四个模块：**Wav2Vec、BERT、MakeData、DeepNetwork**。

- **Wav2Vec**：负责语音转文字，并把语音升维成高维特征，输出维度 `[1, 768]`。
- **BERT**：对语音识别得到的文本做语义编码，输出语义特征 `[1, 768]`。
- **线性空间转换**：两路特征在拼接前各自经过独立的线性映射层，做归一化与空间对齐，保证维度与尺度一致（否则融合阶段难以收敛）。
- **DeepNetwork（特征融合）**：基于 PyTorch 实现。

融合流程：
1. 两个 768 维向量线性拼接 → **1536 维联合特征**；
2. 施加**两层 8 头自注意力**，捕捉语音与语义的关联、强化内部权重结构；
3. 线性层映射回 **768 维**；
4. 进入 **MLP 回归**，完成向量空间的连续映射，网络遵循“**逐步放大—再逐步缩小**”的结构（升维增加容量、降维提取高层特征），避免特征过快收敛造成细节损失；
5. 输出 `[1, 14]` 向量：**前 7 维为智能体当前情绪状态，后 7 维为智能体对用户情绪的预测**，每维取值范围 `[-1, 1]`。

### 七维双向情绪

七类情绪维度采用**双向对立**设计，负向 ↔ 正向一一对应：

| 负向 | 正向 |
| --- | --- |
| 厌倦 | 好奇 |
| 悲伤 | 开心 |
| 高冷 | 热情 |
| 焦虑 | 轻松 |
| 愤怒 | 平静 |
| 厌恶 | 喜爱 |
| 恐惧 | 勇敢 |

感知层中，`MakeData` 负责训练数据的读取与结构化；为兼顾大规模数据，采用**懒加载**策略：训练时按 batch 随机生成数据地址，再按需读取并即时转成特征，避免一次性加载导致内存过高。

## 4. 处理层：情绪的动态修正

处理层相当于智能体的“中枢计算系统”，由**性格修正、长期记忆、情感态度、情感传染**四个模块构成，对感知层输出的情绪做耦合修正后，输出修正后的机器人情绪、用户情绪，以及更新后的信任值与爱恨值，并通过日志写入数据库。

*图2　处理层流程总图。*

### 4.1 长期记忆模块

目标是从交互中形成稳定的情绪与语义记忆：

- 日常对话先进入**短期记忆**（约 2–3 天内的输入），以文本形式存放；
- 系统持续监测当前情绪向量的幅度，当某次交互情绪幅度**超过阈值**，判定为“强烈情绪”，把该次对话的**文本特征、语音特征与情绪结果**写入长期记忆数据库；
- 新情绪产生时，与长期记忆库向量做**内积相似度**；超过设定阈值则触发对应长期记忆的**主导情绪**；
- 该情绪经**时间衰减函数**处理后与当前情绪**线性叠加**，影响最终输出。

### 4.2 情感态度模块（信任度 / 爱恨度）

维护两个核心态度变量——**信任度**与**爱恨度**，由两类因子共同驱动：

- **熟悉度因子**：由“最近一次交互时间与当前时间的差值”计算，长期无交互会下降；
- **情绪反馈因子**：由交互中用户引起的情绪值变化累积。

熟悉度带遗忘因子：

$$F_t = F_{t-1}\times e^{-x} + 0.01\times |s|,\qquad F_t\in[0,1]$$

其中 $x$ 为距上次对话的天数，$|s|$ 为综合情感值的绝对值。综合情感值、互动平衡、爱恨度、信任度依次定义如下：

$$S=\sum_{i=0}^{6} m_i e_i,\qquad m_i=[0.1,0.18,0.12,0.15,0.18,0.15,0.12],\qquad S\in[-1,1]$$

$$p_{nt}=\frac{P_t-N_t}{P_t+N_t+1}\in[-1,1]$$

$$A_t = A_{t-1} + 0.05\times s_t + 0.03\times p_{nt},\qquad A_t\in[-1,1]$$

$$T_t = T_{t-1} + 0.04\times F_t + 0.06\times S_t + 0.02\times p_{nt},\qquad T_t\in[0,1]$$

其中 $e_i$ 为第 $i$ 类情绪强度，$P_t / N_t$ 为正向 / 负向综合情感出现次数。该模块用线性因子模型对即时情绪做偏移，使情绪表现符合其对用户的主观态度（例如信任值更高时更容易被安抚）。

### 4.3 情感传染模块

基于心理学“情绪传染”机制，计算机器人与用户情绪向量的**内积相似度**，得到**情绪传染因子**（越高表示越接近、越易共情），再对相关情绪维度做拉近或弱化，使其向用户情绪靠拢，呈现“共情能力 / 情绪同步性”。

![图5 情绪传染模块流程图](/images/emotion-agent/fig05.jpg)

*图5　情绪传染模块流程图。*

### 4.4 性格修正模块

依据智能体的性格（MBTI）参数调整情绪敏感度：同样刺激下，理性倾向强者更不容易产生强烈愤怒，系统会对“开心—悲伤”“平静—愤怒”等维度适度削弱，使输出更符合性格。修正通过预设人格系数的线性调节方程对各情绪维度做动态缩放。

## 5. 决策层：情绪驱动的策略演化

决策层是行为选择与策略自适应更新中心，把量化情绪与心理模型转化为可执行动作，并驱动人格形成。它由三个模块组成：**Decisionor（动作决策）、Updateor（策略更新）、GetData（外部数据加载）**。

采用强化学习的策略梯度思想，以**智能体情绪、用户情绪、信任度、爱恨度**四个维度构成状态向量，确定当前状态 $S$（每种状态有 $S$ 种）。

![图7 决策层流程总图](/images/emotion-agent/fig07.jpg)

*图7　决策层流程总图。*

### 5.1 三个动作空间（链式决策）

1. **意图决策**：回答、肯定、否定、建议、情感回应、请求、回避等（为什么回应）；
2. **内容决策**：简单直接、感性共情、幽默轻松、权威专业等（回应什么内容）；
3. **策略风格决策**：热情主动、冷漠高冷、真诚坦白、疲惫厌倦、生气攻击等（用什么风格与温度）。

### 5.2 策略更新与奖励

机器人情感按如下方式递推（原文两侧上标相同，按递推含义应为当前值与上一时刻值）：

$$E_i^{(t)} = 0.5\times E_i^{(t-1)} + 0.5\times e_i,\qquad E_{robot}\in[-1,1]$$

`Decisionor` 依据当前策略 Policy 与状态向量对动作概率分布采样；用户对本次回复的下一轮回应被计算成奖励。`Updateor` 把 7 类情绪取平均，正为正向、负为负向，据此对策略概率做强化 / 削弱：

$$p' = p \pm (a\cdot r)\cdot\gamma + 0.0001,\qquad a\in[30,200],\quad r\in[-1,1],\quad \gamma\in(0,3]$$

其中 $a$ 为缩放因子，$r$ 为奖励值，$\gamma$ 为（大五人格）人格修正因子，$0.0001$ 为最小平滑增量，$\pm$ 由情绪正负决定。人格修正因子规模约为 $5\times(10+8+7)$（大五人格 × 三个动作空间的动作数）。更新结果经 Softmax 归一化后写回策略表：

$$P_i=\frac{e^{p'_i}}{\sum_j e^{p'_j}}$$

`GetData` 负责加载大五人格权重更新与 MBTI 动作映射，形成人格权重表与 MBTI 动作映射表（以 Excel 等格式本地存储，便于编辑）；`Decisionor` 输出还包括用户的 MBTI 累计特征表——每当系统选择特定动作，就把对应人格维度值按规则累加，用于逐步推断用户人格倾向。

**收敛性**：缩放因子约经过 400–600 次强化即可让系统稳定收敛，每种状态在当前参数下的“预计强化基数 600 次”后会彻底收敛。

## 6. 关键设计要点

1. **可解释性**：通过量化情绪、人格参数、策略概率等可观测变量构建决策链路，情绪演化、行为选择与响应生成均可追踪、可解释。
2. **长期一致性**：以 `RAG 数据库 + 数学建模` 的长期记忆机制，通过内积匹配、阈值触发、时间衰减实现“事件级记忆”的固化与调用，保持长期关系连贯。
3. **可量化情绪体系**：七维双向情绪 + 信任度 / 爱恨度态度系统 + 情感传染 + 人格修正，构成可演化的高拟真心理模型。
4. **三技术融合**：深度学习（感知）+ 数学建模（人格与情绪）+ 强化学习（策略演化），形成多模态（语音 + 文本）情绪决策闭环。
5. **平滑的特征融合**：线性映射对齐 → 拼接 → 自注意力 → MLP“先放大后缩小”，兼顾收敛稳定与细节保留。

## 7. 适用场景

情绪陪伴机器人、心理辅助陪伴、教育情绪互动系统、个性化虚拟助手、游戏 NPC 智能人格系统、虚拟数字人、养成类 AI、AI 伴侣、老人照护等。
